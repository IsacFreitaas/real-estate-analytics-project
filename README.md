## 1. Objetivo

Este projeto tem como objetivo analisar dados relacionados ao mercado imobiliário e investigar quais características estão associadas ao valor dos imóveis.

A partir da análise dos dados, será desenvolvido um modelo simples de Machine Learning para avaliar a possibilidade de estimar o valor dos imóveis com base em suas características.
